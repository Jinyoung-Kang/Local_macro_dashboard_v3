## 4단계 — 정해 주셔야 하거나 직접 넣으셔야 하는 것

| 내용 | 확인 | 제안 |
|---|---|---|
| `audit_log` 보존 기한 | 로컬 4행·48kB. 지우는 작업은 되돌릴 수 없음 | **1년** 지난 기록을 정기 작업으로 정리(세션 정리와 같은 자리). 기간만 정해 주시면 됨 |
| RDS `sslmode=require` → `verify-full` | 지금은 암호화만 하고 서버 인증서를 검증하지 않음(VPC 안) | 공개된 RDS CA 묶음을 이미지에 넣고 `verify-full`. AWS 연결이 깨질 수 있어 반영 때 되돌릴 이미지를 남겨 두고 확인 |
| 컨테이너 권한 줄이기(`cap_drop: ALL`, `no-new-privileges`) | compose에 없음 | 로컬·QA 스택에서 네 컨테이너가 다 뜨는지 확인 뒤 AWS |
| 로컬 DB 기본 비밀번호 `macro` | postgres는 127.0.0.1에만 열림 | 바꾸려면 새 값을 `.env`에 **직접** 넣으셔야 함. 기존 볼륨에 `ALTER ROLE`을 거는 스크립트만 제가 만듦. 위험이 낮아 **하지 않아도 됨** |
